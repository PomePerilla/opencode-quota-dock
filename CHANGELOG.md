# Changelog

## 0.1.6

First public MVP for OpenCode Desktop 2.3.0 on Windows.

- Multiple Codex subscription accounts in the bottom-left sidebar.
- One row per account, with separate five-hour and weekly progress bars and reset countdowns.
- Fixed countdown columns that keep bars aligned as digit counts change.
- Five-hour bar color `#c5dbfb`.
- OpenCode native settings layout, buttons, fields, selectors and switches.
- Account search, sort, rename, pin, monitoring and refresh controls.
- Experimental Codex App Server bridge for compatible legacy OAuth connections.

See [compatibility](docs/compatibility.md) for supported authentication and versions.
